# examples/

Фікстури відповідей API для режиму `mock` (структура збережена, дані анонімізовано).

- Усі значення замінено на явні плейсхолдери: ПІБ → `Учень N` / `Викладач N` / `Співробітник N` / `Прізвище Ім'я N`,
  e-mail → `user@example.com`, телефони → `380000000000`, посилання на файли → `.../files/DEMOFILE`,
  JWT → `<JWT_PLACEHOLDER>`, ID осіб/груп → вигадані числа, вільний текст → `Текст прикладу`.
- Файли першого рівня використовує код (`app/fixtures.py`); `live/` — довідкові зліпки форм відповідей.
- Свої сирі знімки робіть через `tools/probe_verify.py`: вони потрапляють до `examples/_raw_live/`
  (у `.gitignore`), бо містять персональні дані. Не комітьте їх.
